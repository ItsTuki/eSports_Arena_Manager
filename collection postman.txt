- eSports Arena Manager
Orden recomendado para probar el flujo completo

Notas:
- Antes de probar, iniciar XAMPP y levantar MySQL.
- Los IDs usados abajo asumen una base limpia.
- Si ya probaste antes, limpia las tablas o ajusta los IDs segun lo creado.

============================================================
PASO 1 - Crear usuario administrador
============================================================
Metodo: POST
URL: http://localhost:8081/api/v1/usuarios
Body JSON:

{
  "nombre": "Admin Uno",
  "nickname": "admin1",
  "email": "admin@example.com",
  "rol": "ADMINISTRADOR"
}

Resultado esperado:
- Usuario creado con id 1.

============================================================
PASO 2 - Crear cuenta de acceso para administrador
============================================================
Metodo: POST
